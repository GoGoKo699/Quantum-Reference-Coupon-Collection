# Learning route

Suppose the labels are 1, 2, 3, and 4. One source gives a uniform quantum superposition over the present labels. A second source gives a uniform superposition over all four. The sources use the same unknown phase for each label. The task is to identify which labels are missing from the first source, while counting every copy taken from either source.

Start with the [worked pair and block](BRS_BRIDGE.md#one-missing-label-two-ways-to-compare). Then follow the [30-milestone map](MILESTONES.md), which builds from the source model to the optimal copy tradeoffs. The [Bartlett–Rudolph–Spekkens bridge](BRS_BRIDGE.md) connects the review's treatment of incomplete phase references to the histogram and comparison measurements used here.

The [scientific account](../science/README.md) gives exact assumptions, bounds, and proofs. The [verification route](../verification/README.md) provides small checks of the measurement and inference formulas.
