# Scientific account

Start with the [source model](model.md) and its minimax success criterion. A [paired receiver](paired-receiver.md) turns antisymmetric outcomes into missing–present edges. The [histogram converse](histogram-converse.md) says what an arbitrary collective receiver can learn about labels it has never observed and determines the exact zero-reference optimum.

Two constructions resolve different resource regimes. The [block receiver](block-receiver.md) uses an independent basis sample and symmetry tests to approach the histogram upper bound when the signal budget grows faster than linearly. The [collective receiver](linear-budget.md) uses a conditional Gram matrix to determine finite minimax success and derive the sharp fixed-$m$ limit at linear budgets.

The [phase mismatch analysis](phase-mismatch.md) explains why shared phases are a substantive input condition. The [resource accounting](resources.md) records what the copy statements charge and the different implementation costs of the receivers.
